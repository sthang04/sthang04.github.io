# Feed My Cats! - Vue 3 Week 6

## Setup with pnpm
Install Node.js (a supported LTS version) and pnpm first.

To scaffold from scratch in the recording:
```sh
pnpm create vite feed-my-cats --template vue
cd feed-my-cats
pnpm install
pnpm add bootstrap
pnpm dev
```

For this supplied project, run from its folder:
```sh
pnpm install
pnpm dev
```

The supplied project uses Vue 3, Vite, Bootstrap CSS, and no router.
The `src/views` folder follows the lecture convention, although the page is directly imported by App.vue for simplicity.
